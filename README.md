## Basic Command
```bash
# Cek Node ID
nano ~/node_info.json
# Generate Referal
./pop --gen-referral-route
# Cek Poin
./pop --points
# Cek Status Node
./pop --status
# Masuk Screen Pipe
screen -r pipe
# Keluar Screen
CTRL+A+D
```
